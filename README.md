# قادة الحروب — WAR COMMANDERS v0.18

**الإصدار الحالي: 30 خريطة، 15 نوع قوات، 3 خرائط واسعة، 7 مؤثرات صوتية أصلية جديدة، وواجهة قتال أفقية.**

شغّل `node server.js` للعب الجماعي من المتصفح، أو افتح `play-offline.html` للعب الفردي دون خادم. الاختبارات: `npm test`. التفاصيل في `CHANGELOG_v0.18_AR.md` و`TEST_REPORT_v0.18_AR.md`.

## الميزات والإصدارات السابقة

لعبة RTS عربية تجريبية تعمل بالمتصفح وNode.js 22؛ 27 خريطة ومهمة، 11 نوعًا من القوات، ونظام استطلاع، وتشكيلات عسكرية، وأوامر دوريات حراسة. تدعم اللعب الفردي وغرف 1v1 و2v2.

## الجديد في v0.14

- **دورية حراسة:** حدد وحداتك، اضغط «↔ دورية»، ثم المس نقطة في ساحة المعركة. تتحرك الوحدات ذهابًا وإيابًا بين موقعها الأول والنقطة المختارة، وتشتبك مع العدو ضمن قواعد الاستطلاع.
- إلغاء الدورية عند إعطاء أمر حركة جديد أو «الثبات». وفي الخريطة المصغرة يظهر خط الدورية للوحدات الصديقة.
- تحسين استجابة الخصم الذكي للتهديدات التي تقترب من مركز القيادة، وتغيير ترتيب أولويات نقاط السيطرة.
- 3 خرائط جديدة: طريق الإمداد، حراسة المضيق، والسور الأخير. أصبح الإجمالي 27 مهمة.
- التحقق من صلاحيات الفرق على الخادم ومنع إصدار أوامر دوريات لوحدات الخصم.

## التشغيل

```bash
node server.js
```

افتح `http://localhost:8787` (أو المنفذ الذي تختاره باستخدام المتغير `PORT`). للعب الفردي دون خادم افتح `play-offline.html`.

## الاختبارات

```bash
npm test
```

## ملاحظات

الخادم أحادي العملية؛ الغرف في ذاكرة الخادم وتضيع عند إعادة التشغيل. وضع الدورية محاكاة تجريبية، ولم يتم إجراء اختبارات تحميل عامة أو اعتماد نسخة Android أصلية في هذا الإصدار.


## إضافات v0.15
- مجموعات تحكم محلية (4 خانات) بحفظ مطول على الجوال أو Shift+1–4 على لوحة المفاتيح، والاستدعاء بنقرة واحدة أو 1–4.
- إعادة الاتصال بالمباريات: تحفظ مجموعات التحكم في Session Storage فقط، مقيدة بالغرفة والفريق، ولا تُرسل للخادم.
- تحسينات عرض WebGL: تقليل تفاصيل الوحدات البعيدة خارج مجال المشاهدة، وعرض اقتصادي متكيف عند انخفاض معدل الإطارات.
- تبقى سلطة أوامر الوحدات وتحقق الرؤية في الخادم.

## إضافات v0.16
- مخطط تكتيكي حي يعرض أماكن الوحدات في التشكيلات الأربعة.
- مسافات متعددة معتمدة من الخادم: `tight` و`standard` و`wide`.
- تفاصيل رسومية جديدة للمركبات والسفن والمروحيات في WebGL مع الحفاظ على وضع الرسم الاقتصادي.
- 88 اختبارًا آليًا ناجحًا؛ راجع `TEST_REPORT_v0.16_AR.md` لمعرفة قيود اختبار المتصفح.
