# قادة الحروب — v0.17 (واجهة الجوال الأفقية)

## ما تغير
- عند اللعب على هاتف بالعرض، تمتد خريطة المعركة على كامل مساحة الشاشة المتاحة للصفحة.
- يظهر الرادار أعلى اليمين، وشريط الموارد أعلى الصفحة، وأزرار التكبير والتحريك يسارها.
- يظهر شريط منخفض أسفل الصفحة: القوات، المباني، التطوير، الأوامر، المجموعات المحفوظة.
- جميع الأوامر تستخدم أزرار اللعبة الأصلية ومحرك اللعب الحالي، وليس واجهة استعراضية منفصلة.
- يظهر تنبيه تدوير الهاتف عند فتح المعركة في الوضع العمودي.
- أضيف زر ملء الشاشة يحاول استخدام Fullscreen API وتثبيت landscape على المتصفحات الداعمة.
- أعيد ترتيب الكاميرا الأولية للشاشات الأفقية الصغيرة لعدم تكبير القاعدة بشكل مبالغ فيه.

## الاستخدام على iPhone
1. افتح اللعبة في Safari.
2. أوقف «قفل الاتجاه الرأسي» من مركز التحكم.
3. أدر الهاتف إلى الوضع الأفقي، ثم اضغط بدء اللعب.
4. استخدم علامات التبويب أسفل الشاشة لعرض القوات والأسلحة والمباني وغيرها.

**قيد تقني:** على Safari في iPhone لا يستطيع موقع ويب عادي فرض تدوير الجهاز أو إخفاء جميع أشرطة المتصفح. ملء الشاشة يطبّق حيث تسمح المنصة، بينما يبقى التخطيط الأفقي وتجربة PWA الممكنة بديلًا.

## الاختبار
- `npm test` من مجلد المشروع.
- تجربة فعلية باستخدام Chromium بمحاكاة هاتف 844x390 و667x375 و390x844، بالإضافة إلى كمبيوتر.
- اختبار تجنيد المشاة من الشريط السفلي، اختيار بناء برج، أوامر التشكيل، التنقل والرادار.
- لا يتضمن الإصدار تطبيق Android/iOS أصليًا جديدًا.

## التشغيل المحلي
```sh
node server.js
```
ثم افتح `http://localhost:8787` (أو منفذ PORT البيئي).

## النشر
ارفع `War_Commanders_v0.17_Render_Deploy.zip` إلى GitHub واستبدل Dockerfile الموجود في المستودع بالملف المرفق في حزمة التحديث؛ يبدأ نشر Render عندما يتعرف على الالتزام الجديد، أو نفذ النشر اليدوي إذا لزم.
